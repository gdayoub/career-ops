## B — Role Description

The Service Quality Reasoning (SQR) team continuously improves the Waymo Driver's reasoning logic for pullover decisions — determining where autonomous vehicles should safely, efficiently, and predictably pull over for passengers.

**Responsibilities:**
- Mine existing test sets to understand driving behaviors and trends
- Propose and implement auto-labeling logic to expand and improve the existing system
- Analyze patterns in autonomous vehicle behavior data

**Required Qualifications:**
- Currently pursuing BS or MS in Computer Science or related field
- Hands-on experience with SQL
- Strong data analysis skills

**Preferred:**
- Python, C++
- Experience with data pipelines and backend development
- ML/labeling experience
